# Usuarios
## Crear, administrar y visualizar usuarios
## Responsabilidades
- Crear usuarios
- Actualizar datos de usuarios
- Dar de baja usuarios
- Delegar responsabilidades y roles a usuarios
- Validar credenciales de usuarios

# Ventas
## Crear, administrar y visualizar ventas
## Responsabilidades
- Crear ventas
- Actualizar datos de ventas
- Dar de baja ventas
- Seleccionar detalles de ventas de acuerdo a período de ventas específico
- Seleccionar que usuarios pueden tocar información sensible de una venta determinada

# Productos
## Crear, administrar y visualizar productos
## Responsabilidades
- Crear productos
- Actualizar datos de productos
- Dar de baja productos
- Actualizar estado de productos
- Seleccionar usuarios y su capacidad que tiene dentro del sistema para crear o actualizar información sensible del producto
- Crear nuevo producto en el módulo Bodega

# Bodega
## Crear, administrar y visualizar productos existentes en Bodega
## Responsabilidades
- Crear producto en Bódega
- Actualizar información de producto en bódega
- Seleccionar producto en Bódega y realizar traspaso a una sucursal determinada
# Reportes
## Crear, administrar y visualizar reportes
## Responsabilidades
- Crear reportes
- Seleccionar un reporte determinado de acuerdo al rol de usuario
- Seleccionar un reporte determinado de acuerdo al tipo de dato seleccionado por el usuario
- Seleccionar información del sistema de acuerdo a un período de tiempo determinado

# Historial Movimientos
## Crear, administrar y visualizar movimientos de historicos de la información más relevante del sistema
## Responsabilidades
- Crear un nuevo histórico cuando se crea un nuevo producto
- Actualizar y adicionar un histórico de acuerdo a un producto que ya este dado de alta en el sistema
- Seleccionar un conjunto de históricos de acuerdo a un tiempo determinado
